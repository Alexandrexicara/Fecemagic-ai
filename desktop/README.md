# FaceMagic AI Desktop — plano técnico

Este diretório documenta o futuro aplicativo Windows; ainda não contém um executável nem driver de câmera virtual.

## Módulos previstos
1. Captura de webcam com permissão explícita.
2. Rastreamento de rosto e inferência em tempo real com modelo licenciado.
3. Pré-visualização com controles de ligar/desligar e indicador visível de efeito de IA.
4. Saída de câmera virtual usando mecanismo compatível com Windows.
5. Testes por aplicativo: cada cliente (WhatsApp Desktop, Messenger, Zoom, Meet etc.) deve ser validado individualmente.

A câmera virtual não será instalada pelo site. Android não oferece uma forma genérica e confiável de substituir a câmera para qualquer aplicativo de terceiros.
